Project Overview

以強資螺絲工廠既有網站為自主 UI/UX 練習對象，重新檢視企業網站中的資訊架構、產品分類、訂製需求與聯絡入口。優化版本將內容整理成首頁、關於我們、產品介紹、產品分類、訂製與聯絡等主要頁面，讓訪客可以依照不同任務逐步瀏覽。

The Challenge

原網站雖然提供公司介紹、營業項目、產品分類與聯絡資訊，但內容主要透過傳統文字導覽與分散頁面呈現。對第一次進入網站的訪客來說，需要自行理解網站層級，也不容易快速判斷產品分類與下一步的詢問方式。

Our Approach

以「認識公司、瀏覽產品、提出訂製需求、取得聯絡方式」四個主要任務重新整理內容，並透過卡片式入口、分類導覽、獨立訂製頁與集中式聯絡資訊，建立更清楚的企業網站瀏覽路徑。

Design Outcomes

本案為自主練習，尚未進行正式使用者測試，因此不使用轉換率或瀏覽量等商業成效數據。以下成果聚焦於資訊架構與介面設計的改善方向。

Key Features

以任務導向的資訊架構取代單純的文字堆疊，讓企業網站的核心內容更容易被找到與理解。

Product Category Navigation

將螺絲、螺帽、華司、工具與其他產品分成清楚入口，方便使用者依需求縮小瀏覽範圍。

Customization Entry Point

將訂製服務獨立呈現，回應特殊規格、材質或製造需求，讓訪客更快找到詢問方向。

Responsive Web Experience

讓首頁入口、產品卡片與聯絡資訊在不同螢幕尺寸上維持清楚的閱讀順序。

Contact Information Access

集中地址、電話、傳真與 Email，降低使用者尋找詢問與合作管道的成本。

Project Reflection

UI/UX 不只是重新安排畫面，也是在整理使用者與資訊之間的關係。這次自主練習讓我理解到，工業製造商網站的設計重點不一定是增加大量視覺效果，而是讓產品、製造能力與詢問流程形成清楚的關係。

由於本案為自主練習，後續若要進一步驗證設計，仍可加入實際使用者訪談、任務測試與企業端回饋，確認產品分類與訂製流程是否符合真實使用情境。
